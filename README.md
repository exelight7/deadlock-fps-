# Deadlock FPS Studio

برنامج مكتبي مفتوح المصدر لتخفيف رسوم Deadlock على **Windows وLinux**. واجهة عربية، تبسيط الخامات، تركيب مودات ذكي، معاينة ونسخ احتياطية. **الإصدار 1.0.1 لا يغيّر دقة الشاشة أو دقة العرض الداخلية أو إعدادات FSR/DLSS في أي وضع.**

![الواجهة](docs/screenshot.png)

## تشغيل البرنامج

حمّل حزمة نظامك من [Releases](https://github.com/exelight7/deadlock-fps-/releases/latest)، فك الضغط **كاملًا** ثم شغّل `DeadlockFPSStudio.exe` في Windows أو `DeadlockFPSStudio` في Linux. لا يحتاج البناء المحمول إلى تثبيت Python. بناء GitHub لنظام Linux يُنتج على Ubuntu 22.04؛ البناء المحلي يستهدف نظام البناء نفسه. بنية x64 فقط.

للتشغيل من المصدر: ثبّت Python 3.12 ثم افتح `run-windows.bat` أو شغّل `./run-linux.sh`. يحتاج التشغيل الأول إلى الإنترنت لتنزيل الاعتماديات. في Linux قد تحتاج حزمة `python3-venv` ومكتبات Qt النظامية مثل EGL وOpenGL وxcb-cursor. يمكن استخدام Wayland عبر `QT_QPA_PLATFORM=wayland` أو X11 عبر `QT_QPA_PLATFORM=xcb` حسب النظام.

## الاستخدام

1. شغّل اللعبة مرة واحدة لإنشاء إعدادات الفيديو، ثم أغلقها.
2. افتح البرنامج. يكتشف Steam ومكتباته تلقائيًا، أو اختر مجلد `Deadlock` يدويًا.
3. اختر حساب Steam المطلوب من قائمة ملفات الفيديو؛ لا يغيّر حساباتك الأخرى.
4. اختر **متوازن** أو **أداء قوي** أو **أقصى تخفيف**، ثم عدّل الرسوم حسب حاجتك.
5. صفحة المودات: يكتشف البرنامج حزمة MODS بجانبه أو في التنزيلات تلقائيًا. يمكنك أيضًا استيراد ZIP أو مجلد أو ملفات VPK. تُحفظ المودات في مكتبة محلية دائمة، ويُتعرف عليها بمحتواها حتى لو تغيرت أسماؤها. اختر المودات واضغط **تركيب / تحديث المودات المختارة** لتركيبها وحدها دون تغيير الرسوم. إلغاء الاختيار ثم التركيب يزيل مودات البرنامج المحددة.
6. اضغط **معاينة وتطبيق**، راجع الفروقات، ثم طبّق. جرّب وضوح المؤثرات في التدريب.

الخامات لها خمسة اختيارات واضحة: خامات مفصلة، تخفيف بسيط، تخفيف متوسط، خامات بسيطة، أبسط خامات. تتوفر أيضًا خيارات الظلال والضباب والوهج والتظليل المحيطي والجزيئات وتخفيف المعالج. حد الإطارات: 0–500، والصفر بدون حد. جميع الأوضاع تحافظ على دقتك. لا يضمن البرنامج زيادة محددة في الإطارات.

تعطيل تعديلات المحرك يسترجع ملف `gameinfo.gi` الأساسي مع استمرار تعديلات الفيديو والمودات المختارة. التحكم الدقيق في بعض المؤثرات وخيار تخفيف المعالج يتطلب تفعيل تعديلات المحرك.

## الملفات والاسترجاع

- إعدادات الفيديو: `Steam/userdata/<account>/1422450/local/cfg/video.txt`، مع دعم ملف الفيديو داخل اللعبة إن وجد. تُحفظ VendorID وDeviceID وجميع إعدادات الدقة والعرض وFSR/DLSS الحالية، حتى عند إعادة التطبيق أو الاسترجاع من نسخة 1.0.0 القديمة. ملفات JSON القديمة مقبولة لكن يُتجاهل منها scale وwidth وheight. إذا خفّض 1.0.0 دقتك بالفعل، اضبطها مرة واحدة من داخل اللعبة؛ 1.0.1 يحافظ على قيمك الحالية ولا يخمّن دقة بديلة.
- المحرك: `Deadlock/game/citadel/gameinfo.gi`. يُدمج فقط نطاق ConVars الرسومي وSceneSystem المحدد؛ لا يُستبدل الملف بالنسخة القديمة المرفقة.
- المودات: `Deadlock/game/citadel/fps_studio/pak*_dir.vpk`. يُضاف مسار بحث خاص عند الحاجة، ولا يُحذف مجلد addons أو المودات الخارجية.
- النسخ: `Deadlock/.deadlock-fps-studio/`. لا تحذف هذا المجلد ما دمت تريد الاسترجاع. يحفظ الأصل مرة واحدة وحالات ما قبل الاسترجاع في `history`.

إذا غيّر تحديث اللعبة ملفًا مُدارًا، يرفض البرنامج الكتابة فوقه. احفظ الحالة الحالية عبر خيار الاسترجاع المخصص في صفحة النسخ. هذا يعيد نسخة **قديمة** من gameinfo؛ بعد ذلك استخدم Steam → Properties → Installed Files → Verify integrity قبل تطبيق إعدادات جديدة، كي تبني التعديلات على ملف حديث. إذا أزيل البرنامج، تبقى التعديلات حتى الاسترجاع أو إصلاح ملفات اللعبة. Steam Cloud أو اللعبة قد يعيدان كتابة إعدادات الفيديو.

## المودات والملفات المرجعية

قرأنا الحزمة كاملة، وراجعنا بنية VPK ومواردها. يتعارض Remove Name Tags مع Old Healthbars لأنهما يعدّلان `unit_status_overlay_v2.vxml_c`؛ اختيار أحدهما يلغي الآخر تلقائيًا، ويتحقق البرنامج أيضًا من التعارض قبل التركيب. Daylock يغيّر الإضاءة/السماء، وSinner Fix يحتوي نموذجًا وخامة. **حزم المودات والبرامج الخارجية غير معاد توزيعها هنا**؛ استورد المودات من مجلدك الأصلي. يحتفظ المستودع بملفات الإعدادات الأصلية للرجوع إليها في `assets/reference`؛ ليست قالبًا يُكتب بالكامل فوق لعبتك.

قد تتجاهل اللعبة إعدادات معينة أو تتوقف المودات بعد تحديث. لا يستخدم البرنامج حقن DLL أو فتح أوامر مقفلة أو تعديل ملفات التنفيذ. لم يتم قياس FPS أو التحقق من سلوك المودات داخل مباراة. إرشاد DX11 في readme الأصلي يتعلق بمشكلات المؤثرات؛ البرنامج لا يفرض محرك عرض، وLinux يستخدم Vulkan حسب إعداد اللعبة الحالية.

```sh
python -m venv .venv
# Linux:
. .venv/bin/activate
# Windows: .venv\Scripts\activate
python -m pip install -r requirements.txt pyinstaller==6.20.0
python -m unittest discover -s tests -v
python main.py
python build.py
```

Build on the target OS. Outputs are in `dist/`; GitHub Actions tests and packages both platforms and publishes v1.0.1 after successful main builds. Windows executables are unsigned. Linux desktop libraries are still required; this is a portable folder, not an AppImage.
