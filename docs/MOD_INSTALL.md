# تركيب المودات — 2.4.0

افتح المودات من القائمة، أو شغّل التطبيق مع `--mods`.

1. اسحب حزمة ZIP أو ملفات VPK أو مجلد MODS إلى مساحة الإضافة. يمكنك أيضًا اختيارها بزر إضافة حزمة. يتعرف البرنامج على الملفات بمحتواها حتى عند تغيير أسمائها.
2. اضغط بطاقة المود أو مربعها لتحديده. البطاقة الملوّنة تعني أنه مختار، والحالة توضّح إن كان جاهزًا في المكتبة أو مركّبًا في اللعبة. إخفاء الأسماء وشريط الصحة القديم اختياران متعارضان؛ يلغى الآخر تلقائيًا.
3. اضغط فحص وتركيب الاختيار. راجع المودات التي ستبقى في اللعبة ثم أكّد مرة واحدة. تُحفظ الملفات الأصلية قبل التطبيق.

الإضافة تحفظ الملفات في مكتبة البرنامج فقط. التركيب يغيّر المودات ومسار تحميلها، ولا يحتاج تحديد حساب فيديو ولا يغيّر الدقة أو إعدادات الرسوم. أغلق اللعبة قبل التركيب. يعمل الاستيراد والفحص في الخلفية ويمكن إلغاؤهما قبل التطبيق؛ انتظر اكتمال حفظ الملفات عند التأكيد.

لإلغاء مود، أزل تحديده وأعد التطبيق. لإزالة جميع مودات الأداة، امسح كل التحديدات واضغط مراجعة إزالة مودات الأداة. تُسترجع الملفات التي تديرها الأداة من نسخها الأصلية؛ ملفاتك الأخرى تبقى كما هي. إذا غيّرت Steam الملفات بعد التركيب، استخدم إصلاح رجوع الإعدادات في صفحة الرسوم؛ إصلاح تركيب مودات فقط يحافظ على الرسوم.

هذه المكتبة تدعم المودات المرجعية الأربعة المرفقة: Daylock وRemove Name Tags وOld Healthbars وSinner Fix. الملفات غير المعروفة لا تُركّب. استيراد الحزمة الأصلية يعيد الملف التالف في المكتبة. Mod Inspector يوضّح النقص والتلف والتعارضات، لكنه لا يضمن توافق المود مع تحديثات اللعبة؛ جرّب داخل التدريب.
