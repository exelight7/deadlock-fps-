# Deadlock Toolbox 2.1.3

برنامج واحد للرسوم والمودات والسيرفرات على Windows وLinux.

- تصميم فحمي وذهبي، خط عربي مضمّن، وصور تتبدل مع الأقسام.
- تخفيف تدريجي من 0 إلى 200، مع الحفاظ على الدقة والعرض الداخلي وFSR/DLSS. عرض رؤية مستقل من 1.78 إلى 3.50.
- استيراد وتركيب مودات ذكي، معاينة، نسخ احتياطي وإصلاح رجوع الإعدادات. حزم VPK غير مرفقة.
- أعلام وأسماء عربية للسيرفرات، بحث، قياس بنق وحفظ اختيارات.
- اختيار مرئي: سطر ذهبي و✓ وعدّاد. أُزيل زر «اختيار دبي» الذي كان يخفي بقية المناطق.
- أزرار مباشرة للحظر وفك حظر المحدد أو كل قواعد Toolbox. إصلاح إزالة قواعد Windows التي ينشئها netsh.

**التنزيل:** اختر ZIP المناسب، وفكّه كاملًا، ثم افتح DeadlockToolbox.exe في Windows أو DeadlockToolbox في Linux. احتفظ بمجلد _internal. حزمة Windows غير موقعة رقميًا. ملفات SHA256 موجودة للتحقق من التنزيل.

البنق قياس لخوادم Steam الوسيطة، وليس بنق المباراة. الحظر يتطلب صلاحية مدير بعد مراجعة التغييرات، ويزيل Toolbox قواعده الخاصة فقط. في Linux أعد تطبيق الحظر بعد إعادة التشغيل. اختيار منطقة لا يضمن موقع المباراة.
