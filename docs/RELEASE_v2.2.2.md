# Deadlock Toolbox 2.2.2

إضافة Crosshair Designer وPRO Crosshairs إلى أدوات الرسوم والمودات والسيرفرات على **Windows وLinux**.

- واجهة المصمم والمعرض باللغة الإنجليزية، بتصميم جديد وتبويبات **Shape / Outline / Behavior**، ألوان سريعة، ومعاينة مباشرة قابلة للتكبير.
- **50 تصميمًا** مع بحث وفلترة Cross / Dot / Ring / Hybrid: 9 إعدادات منشورة منسوبة للاعبين وصناع محتوى بمصادرها وتواريخها، و41 تصميمًا أصليًا من Toolbox. تصاميم Studio ليست إعدادات منسوبة لمحترفين.
- اختيار التصميم بصريًا ثم تعديله، أو **Apply to Game** لمراجعة الحفظ مباشرة. حفظ محلي، مشاركة برمز Toolbox، واستيراد وتصدير JSON.
- تطبيق على ملفات إعدادات الأبطال الحديثة، مع نسخة احتياطية واسترجاع آخر تغيير. خيار لتوحيد التصميم على تفضيلات الأبطال الموجودة مع الحفاظ على الحساسية والأزرار.
- تصحيح حساب الفراغ في المعاينة، وضبط الأبعاد بالبكسلات الصحيحة، وخيار **Make Static**. التوسّع التجريبي للمعاينة فقط؛ سلوك السلاح والحركة وعلامات الأبطال قد يغيّر الشكل الفعلي. جرّب التصميم في التدريب.
- المعاينة ترسم عند التغيير فقط، والمعرض يعمل دون إنترنت ويستخدم صور بطاقات مخزنة مؤقتًا.

**التنزيل:** فك ZIP المناسب كاملًا ثم افتح `DeadlockToolbox.exe` على Windows أو `DeadlockToolbox` على Linux. احتفظ بمجلد `_internal`. أغلق اللعبة قبل تطبيق الكروس هير أو استرجاعه. رموز `DLTB1.` خاصة بـToolbox؛ رموز `DL.` الأصلية ليست مدعومة في الاستيراد.

إعدادات تخفيف الرسوم، المودات والسيرفرات متاحة كما في الإصدار السابق. دقة اللعبة لا تتغير أثناء التصميم. حزم VPK غير مرفقة، ولا توجد زيادة FPS مضمونة. حزمة Windows غير موقعة رقميًا، وحزمة Linux محمولة وليست AppImage.

البنق قياس لخوادم Steam الوسيطة، وليس بنق المباراة. الحظر وفكّه يقتصران على قواعد Toolbox، ويتطلب التطبيق صلاحية مدير بعد المراجعة.

**التحقق:** فحوص الوحدة والواجهة، فحص تشغيل الحزمتين، واختبار تكامل قواعد جدار حماية Windows ضمن GitHub Actions. بصمات التنزيل في `SHA256SUMS.txt`.

المصدر MIT؛ الصور والبيانات والمكتبات تحت حقوقها الأصلية الموثقة في `THIRD_PARTY.md`. مصادر إعدادات اللاعبين وحدود المعاينة موثقة في `docs/CROSSHAIR_SOURCES.md` و`docs/CROSSHAIR_GUIDE.md`.
