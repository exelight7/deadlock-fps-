# Deadlock Toolbox 2.3.0

أُضيف **Update Center** إلى أدوات الرسوم والمودات والسيرفرات وCrosshair Designer، على **Windows وLinux**.

- يعرض إصدارك، آخر إصدار مستقر من GitHub، تاريخ النشر وملاحظات الإصدار، مع تنبيه في القائمة عند توفر تحديث.
- يختار حزمة Windows x64 أو Linux x64 تلقائيًا، مع تقدم التنزيل، الإلغاء وفتح مجلد التنزيل.
- يتحقق من حجم الحزمة وبصمة **SHA-256** قبل اعتمادها. لا يستبدل الحزمة السابقة إلا بعد نجاح التحقق، ويحذف أجزاء التنزيل عند الإلغاء أو الفشل.
- فحص اختياري عند تشغيل البرنامج، مرة يوميًا بعد فحص ناجح؛ يمكن تعطيله. لا يوجد تنزيل تلقائي أو خدمة فحص دائمة.
- يوضح النتائج المحفوظة عند تعذر الاتصال، ويفرّق بين إصدار عام جديد ونسخة تجريبية أحدث.

**إصلاحات:** توقف مؤشر التحميل بعد اكتمال الفحص؛ منع بدء طلب جديد بعد الإلغاء؛ منع اعتبار نتيجة HTTP 304 ناجحة عند وجود خطأ اتصال؛ إبقاء عنوان الصفحة ثابتًا عند ظهور تنبيه التحديث.

**التركيب:** فك ZIP كاملًا في مجلد جديد بعد إغلاق النسخة القديمة، ثم افتح `DeadlockToolbox.exe` على Windows أو `DeadlockToolbox` على Linux. حدّث اختصار سطح المكتب. ملفات `_internal` وQt ضرورية. التنزيل لا يعدّل ملفات اللعبة أو نسخها الاحتياطية؛ تبقى إعداداتك في مجلداتها الحالية. [دليل Update Center](https://github.com/exelight7/deadlock-fps-/blob/main/docs/UPDATE_CENTER.md).

حزم x64 محمولة؛ حزمة Windows غير موقعة رقميًا، وحزمة Linux ليست AppImage. تطبيق مستقل من المجتمع ومفتوح المصدر. يحافظ تخصيص الرسوم على الدقة وFSR/DLSS؛ المودات VPK غير مرفقة. بنق السيرفرات هو ICMP إلى وسطاء Steam ولا يساوي بالضرورة بنق المباراة.

**التحقق:** اختبارات آلية وواجهات على Windows وLinux، وفحص بدء التشغيل من الحزم الفعلية لصفحتي Crosshair Designer وUpdate Center، وفحص قواعد جدار حماية Windows على مشغّل CI مؤقت. أُجري محليًا فحص HTTPS وتنزيل حزمة كاملة والتحقق من بصمتها عبر مركز التحديثات.
