# Deadlock Toolbox 2.4.0

واجهة جديدة متناسقة وطريقة أسهل لتركيب المودات على **Windows وLinux**، مع **Mod Inspector** لفحص الملفات قبل التطبيق.

- تصميم موحّد للألوان والبطاقات والتنقّل والأزرار، ومساحات تتكيف مع النوافذ الصغيرة. يبقى Crosshair Designer بالإنجليزي ومعرض PRO Crosshairs يحتوي 50 تصميمًا.
- تركيب المودات بثلاث خطوات: **اسحب الحزمة ← اختر البطاقات ← راجع وأكّد**. يدعم ZIP وVPK ومجلد MODS والتعرف على الملفات المرجعية حتى لو تغيّرت أسماؤها.
- الاستيراد والفحص يعملان في الخلفية ويمكن إلغاؤهما قبل التطبيق. بطاقات ملوّنة توضّح الاختيار وحالة المود، وأزرار التركيب ثابتة أسفل الصفحة. تُسترجع مودات الأداة عند إلغاء تحديدها وإعادة التطبيق.
- Mod Inspector يوضح الملفات الناقصة والمعدلة والتالفة، ويتحقق من SHA-256 وبنية VPK، ويكشف التعارضات والتداخلات. ملفات غير مدعومة لا تُركّب.
- التحكم بمستوى التخفيف أصبح مباشرًا من صفحة الرسوم، مع المحافظة على المستوى نفسه في لوحة التحكم.

**إصلاح مهم:** إصلاح تركيب مودات فقط بعد إعادة كتابة ملفات اللعبة يحافظ الآن على إعدادات الرسوم؛ لا يطبق مستوى افتراضيًا. المراجعة تعاد إذا تغيرت الملفات قبل التأكيد، ولا تحتاج عملية تركيب المودات تحديد حساب فيديو. يحافظ التطبيق على الدقة وFSR/DLSS، مع حفظ الأصل قبل التعديل.

**Update Center:** يفحص آخر إصدار مستقر ويختار حزمة نظامك وينزّلها مع التحقق من الحجم وSHA-256. تبقى طريقة التركيب يدوية: أغلق النسخة القديمة، وفك ZIP كاملًا في مجلد جديد، وافتح البرنامج وحدّث الاختصار. لا تنسخ الملف التنفيذي وحده؛ مجلد `_internal` ضروري. إعداداتك ونسخ اللعبة الاحتياطية تبقى في مواقعها السابقة. [دليل التحديثات](https://github.com/exelight7/deadlock-fps-/blob/main/docs/UPDATE_CENTER.md).

حزم x64 محمولة؛ Windows غير موقع رقميًا وLinux ليس AppImage. المودات VPK غير مرفقة بالتنزيل؛ استورد حزمك المرجعية. بنق السيرفرات هو ICMP إلى وسطاء Steam وقد يختلف عن بنق المباراة. توافق المودات مع تحديثات اللعبة يحتاج تجربة داخل التدريب.

**التحقق الآلي:** اختبارات المنطق والواجهات على Windows وLinux، تشغيل الحزم المحمولة لصفحات المودات وMod Inspector وCrosshair Designer وUpdate Center، واختبار قواعد جدار حماية Windows على مشغّل CI مؤقت. لا تُنشر الحزم حتى تنجح هذه الفحوص.
