هوية جديدة كاملة للواجهة على **Windows وLinux x64**. كل الأدوات تعمل كما تعرفها؛ الذي تغيّر هو الشكل وترتيب الشاشات.

- **هوية أصلية:** حبر أسود، أزرق مخضر داكن ونحاس معتّق بروح آرت ديكو. شعار وأيقونات ورسوم جديدة مرسومة بالكود، بدون أي صور خارجية.
- **خطوط جديدة:** Reem Kufi للعناوين و Noto Sans للنصوص، مرفقة مع البرنامج بترخيص حر.
- **شاشات مرتّبة:** كل صفحة تبدأ بعنوانها وسطر إرشاد واحد، والإجراء النهائي ثابت أسفل النافذة.
- **المودات:** منطقة السحب تحمل أزرارها، وبطاقات أوضح للمود المختار والمركّب.
- **السيرفرات:** شريط أدوات أبسط، وصفوف أوضح للمناطق المحددة والبنق.
- **الكروس هير:** شريط واحد للتصميم والحفظ والمشاركة، ومعرض بطاقات جديد.
- **التحديث:** الحالة أولًا، ثم الإصداران جنبًا إلى جنب، ثم الأزرار بترتيب العمل.
- **حالات مقروءة:** رسوم للحالات الفارغة، وألوان واضحة للنجاح والخطأ والتعطيل، وتباين نص يطابق WCAG AA.
- **وضوح أعلى:** كل الرسوم متجهة وتظهر حادة على الشاشات عالية الدقة، والواجهة تتجاوب من 940×680 إلى الشاشات العريضة.

لا تغيير في طريقة عمل الرسوم أو المودات أو السيرفرات أو الكروس هير أو التحديث، وإعداداتك ونسخك الاحتياطية كما هي. أُزيلت الصور القديمة من البرنامج.

**للتحديث من 2.5 وما بعده:** التحديث والتثبيت ← تحقق ← نزّل ← ثبّت.

**القادم من إصدار أقدم:** نزّل الحزمة وفكّها كاملة مرة واحدة، ثم افتح `Install.cmd` على Windows أو شغّل `bash Install.sh` على Linux.
