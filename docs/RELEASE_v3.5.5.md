The biggest change to Deadlock Toolbox so far, for **Windows and Linux x64**: two languages, a reorganised app, and a smarter search for your game.

- **English and Arabic.** English is now the main language and Arabic is one click away in **Settings → Language** (applied after a restart). The whole app mirrors for right-to-left, including the crosshair workspace, which is now available in Arabic too. A first launch on an Arabic system starts in Arabic.
- **Menus rebuilt.** The rail is grouped: **Home**, then **Play** (Performance, Crosshair, Mods, Servers) and **System** (Recovery, Settings), with Updates at the bottom.
- **New Home.** One card says whether Deadlock is on this PC, and six tiles show the state of each tool with a way in.
- **Smart game detection.** The app searches the Steam registry, every Steam library, the usual folders on every drive and the running game. It tells you plainly when the game is linked, still downloading in Steam, missing, or when Steam itself is not found, offers to install it from Steam, and links it by itself the moment it appears.
- **One Performance page.** Presets, the level gauge and the level slider live together; no more two pages for the same setting.
- **Mods and Inspection together.** The inspector is a tab of the Mods page instead of a separate menu entry.
- **One Recovery page.** Undo graphics, crosshair, mods and server blocks from the same place; each one still shows its review first.
- **Settings page.** Language, the settings guard and the update check in one place.

Your game settings, backups and saved selections are untouched. Command-line flags (`--mods`, `--inspector`, `--updates`, `--crosshair`, `--install`) work as before.

**Updating from 2.5 or later:** Updates → Check → Download → Install.

**Coming from an older version:** download and extract the whole package once, then open `Install.cmd` on Windows or run `bash Install.sh` on Linux.
