# Update Center — 2.3.0

مركز تحديثات Deadlock Toolbox على Windows وLinux.

## الاستخدام

- افتح **Update Center** من القائمة الجانبية أو شغّل البرنامج مع `--updates`.
- اضغط **التحقق من التحديثات** لرؤية آخر إصدار مستقر، تاريخ النشر، وملاحظاته. تظهر نقطة بجانب Update Center عند وجود إصدار أحدث.
- تُقارن أرقام الإصدارات وفق SemVer: مثلًا `2.2.10` أحدث من `2.2.2`، و`2.3.0` أحدث من `2.3.0-preview.1`.
- إن كانت نسختك التجريبية أحدث من الإصدار العام، تظهر هذه الحالة صراحة ويُسمى زر التنزيل **تنزيل الإصدار العام (أقدم)**.
- تُختار حزمة Windows x64 أو Linux x64 تلقائيًا. لا يُعرض تنزيل غير متوافق على ARM أو macOS، ولا يُسمح بتنزيل حزمة دون ملف التحقق.
- التنزيل في **Downloads/Deadlock Toolbox/رقم الإصدار/**. بعد نجاحه استخدم **فتح مجلد التنزيل**.
- يمكنك إلغاء الفحص أو التنزيل، أو إغلاق البرنامج أثناءهما. تُحذف الأجزاء غير المكتملة، وتبقى أي حزمة سابقة سليمة حتى نجاح الجديدة.

## تركيب الحزمة

1. انتظر رسالة **تم التحقق من التنزيل**.
2. أغلق النسخة القديمة وفك ZIP كاملًا في مجلد جديد.
3. افتح `DeadlockToolbox.exe` على Windows، أو `DeadlockToolbox` على Linux. حدّث اختصار سطح المكتب للمسار الجديد.

مجلد `_internal` وملفات Qt مطلوبة. لا تنسخ الملف التنفيذي وحده. لا تُستبدل الملفات التنفيذية أثناء التشغيل. التنزيل لا يغيّر ملفات اللعبة أو نسخها الاحتياطية. إعدادات التطبيق محفوظة خارج مجلد البرنامج وتبقى متاحة عند تشغيل النسخة الجديدة بنفس حساب النظام.

## الفحص التلقائي والخصوصية

الفحص عند التشغيل مفعّل افتراضيًا ويمكن تعطيله داخل الصفحة. يبدأ بعد ثلاث ثوانٍ من ظهور التطبيق، وبحد أقصى مرة يوميًا بعد فحص ناجح. تُؤجّل إعادة المحاولات التلقائية ساعة بعد فشل الاتصال؛ الفحص اليدوي متاح فورًا. لا توجد خدمة خلفية أو مؤقت فحص دوري أثناء اللعب، ولا تنزيل تلقائي.

يرسل الفحص طلبًا عامًا إلى GitHub API للمستودع `exelight7/deadlock-fps-`؛ لا يحتاج تسجيل الدخول ولا يرسل إعدادات اللعبة أو بيانات Steam. تُحفظ التفضيلات، ووقت آخر فحص، ومعلومات الإصدار في مجلد `updates` داخل بيانات التطبيق. عند انقطاع الإنترنت تُعرض النتيجة المحفوظة بوضوح؛ يلزم فحص ناجح جديد لتفعيل التنزيل.

## التحقق من التنزيل

تُجلب بيانات آخر إصدار مستقر عبر HTTPS، وتُقبل روابط حزم المستودع نفسه فقط. تحويلات التنزيل محصورة بخوادم GitHub المعتمدة وتظل عبر HTTPS. لا يتجاهل البرنامج أخطاء شهادات TLS.

يُتحقق من حجم ملف `SHA256SUMS.txt` وبصمته المنشورة في API إن توفرت، ثم من توافق بصمة الحزمة معه. تُحسب SHA-256 أثناء التنزيل، ولا يُعتمد ZIP إلا بعد تطابق الحجم والبصمة. البيانات الكبيرة والتالفة والحزم غير المكتملة تُرفض. هذا تحقق سلامة من المصدر المنشور؛ ليس توقيعًا مستقلًا للناشر.

الاتصال عبر Qt Network بصورة غير متزامنة مع مهلة توقف، وقراءة محدودة الذاكرة. لا توجد مكتبة تحديث إضافية أو حلقة رسم/فحص في وضع الخمول.

المراجع التقنية: [GitHub Releases REST API](https://docs.github.com/en/rest/releases/releases)، [Qt Network](https://doc.qt.io/qtforpython-6/PySide6/QtNetwork/index.html).
