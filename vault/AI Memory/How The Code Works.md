# How the code works (internals an AI needs before editing)

Complements [[Architecture Overview]] (layers) and [[Codebase Structure]] (file table). Verified against the code on 2026-11-14.

## Start-up and the window
* `main.py`: `i18n.load()` runs **before** `deadlock_fps.ui` is imported (many strings are built at import time), then `ui.main()`. A `--firewall-plan` mode runs the elevated firewall helper. Flags `--mods`, `--inspector`, `--updates`, `--crosshair`, `--install` open pages (mapped to addresses in `shell.registry.FLAGS`).
* **Home and the game link (Phase 3, 2026-11-14):** `pages/home.py` draws Home; `game_link.py` (`GameLinkMixin`) owns the linked folder, the account list, `game_linked`, detection and `refresh_home()`. The window still exposes `path`, `accounts` and `connection_note`. Tests patch `deadlock_fps.game_link.detect_games`, not the old `legacy.home`. See [[Home Page]].
* **The window (since Phase 2 of the redesign, 2026-11-14):** pages are addressed **by name**, never by number ([[Shell and Page Registry]], [[ADR-015 Pages are addressed by name through one registry]]). `shell/registry.py` `default_registry()` lists 9 places (`home`, `mods`, `performance`, `stats`, `crosshair`, `servers` in the sidebar; `backups`, `settings` pinned at the bottom; `map` hidden) with their tabs. `ui.Window` builds the `Sidebar`/`NavItem`s, a `TopBar` and a `Tabs` row from it, and keeps every page widget in `self.slots[<slot>]` inside `self.stack`. `navigate('mods.health')` resolves address → slot; `current_address`, `current_slot`. The 17 old pages sit in slots `home, graphics, classic, recovery, servers, crosshair, updates, inspector, settings, sources, hub, installed, compatibility, downloads, graph, store, stats` (table of addresses in [[Shell and Page Registry]]). The old window methods live in mixins under `deadlock_fps/shell/base.py/` (`home.py` game link and Home, `performance.py`, `backups.py`, `general.py` Settings > General and the guard, `classic.py`). Tests that stop game detection patch `deadlock_fps.legacy.home.detect_games` (and `video_files`), the performance window is `deadlock_fps.legacy.performance.PerfDialog`. `design.PAGES` and `design.NAV_ICONS` are dicts keyed by slot; `UtilityHeader(slot, …)`. The look (`workspace.json` `look`) is applied by `ui.start_look()`; `shell/theme.py` holds the current `Theme` from `tokens.json`. `self.path` (QLineEdit) holds the linked game folder; `detection.manifest(root)` reads Steam's `appmanifest` (build id).
* `Window` creates `RepositoryPage`, then `ModService(self.repositories.manager, lambda: self.path.text(), self)`, then the Hub, Installed, Compatibility, Downloads and Graph pages, then `StoreService(parent=self)` and `BrowsePage` (slot `store`; the service cancels its sync on `aboutToQuit`), then `StatsService(parent=self)` and `StatsPage(self, service, self.steam_account)` (slot `stats`). A 400 ms single-shot timer re-emits `service.changed` when the game path text changes. `closeEvent` refuses to close while `mod_service.busy`.

## `core.Studio` (legacy, central, delicate)
* One folder per game: `<game>/.deadlock-fps-studio/` with `state.json` (schema 2: `files{path→{backup, existed, applied, expected, owned}}`, `settings`, `graphics_managed`, **`addons`**), `originals/`, `applied/`, `rebased/`, `history/<stamp>/`.
* `plan()` (graphics + reference mods), `plan_mods()` (mods only), `apply(plan, settings, mod_only, addons=None)`, `restore(preserve_changes)`, `repair(mod_folder)` (rebases on a patched file by undoing only the recorded footprint), `baseline()` (raises Arabic "settings changed" if a managed file differs from what was applied), `drift()`, `enable_addons(mod_folder)` (new). Changes are transactional with rollback.
* `gameinfo.gi` edits use `kv.py`, a lossless KeyValues editor (`section`, `update`, `add_search_path` for `citadel/fps_studio`, **`add_addons_path`/`has_addons_path` for `citadel/addons`**, inserted above the first `citadel` entry).
* Reference mods: `settings.MODS` = daylock `pak01_dir.vpk`, names `pak02`, health `pak03`, sinner `pak26`; recognised **only** by the SHA-256s in `mods.HASHES`; the library lives in AppData; installed into `game/citadel/fps_studio/`. Known conflict: names ⇄ health.
* `core.vpk_entries(bytes_or_path)` is the old VPK reader (single-file only); `installer/vpk.py` is the new streaming one.

## `repos/` (catalogue engine, no Qt)
* **Spec** (`spec.py`): index `schema: "deadlock-mod-repository"`, `schema_version: "1.x"`; list schema `deadlock-mod-repository-list`; the index file name is `deadlock-repo.json`. Limits: 8 MiB index, 5 000 mods, 200 versions per mod, 2 GiB package, 12 screenshots, 8 mirrors, 32 list items. Mod id `[a-z0-9][a-z0-9._-]{0,62}[a-z0-9]` (min 2 chars: `a` is rejected). Versions are 1-4 numeric parts plus optional SemVer pre-release. `package.format` ∈ {vpk, zip}, `install.type` = `vpk` only; unknown values keep the version but mark `unsupported_reason`. Bad entries are skipped into `RepositoryIndex.warnings`; structural problems raise `RepoError`. `derived=True` relaxes size/author for provider-translated catalogues. `install.files[].source` must match a strict relative-path regex and end in `.vpk`.
* **Identity:** canonical ids `github:owner/repo` (lower-case), `gitlab:host/path`, `https:host/path`, `local:<slug>`; `RepositorySource.uid = sha256(id)[:16]` names cache files.
* **Providers** (`providers/`): `GitHubProvider` tries API metadata, then `deadlock-repo.json` on the default branch (raw.githubusercontent.com), then a copy attached to a release, then translates `.vpk` assets (asset URL must be exactly `github.com/<o>/<r>/releases/download/<tag>/<name>`), `.zip`-only ⇒ **MANUAL**, else UNSUPPORTED. `GitLabProvider` mirrors it via `/api/v4` (self-hosted needs the explicit provider choice). `NativeHttpsProvider` fetches the URL or `<url>/deadlock-repo.json` with `If-None-Match`. `ProviderRegistry.register(provider, first=…)` adds sources without touching other code.
* **Transport:** `UrllibTransport` (hand-built opener with only the pinned HTTPS handler; `resolve_public()` refuses any non-global DNS answer and the socket connects to that exact address; ≤ 5 redirects each re-validated; no compression). `get()` returns a `Response` for any status; `download(url, dest, max_bytes, expected_size, progress, cancel)` streams, hashes, removes partials, never deletes a file it did not create. Tests use `FakeTransport`/`ServingTransport`.
* **Trust:** `assets/trust/registry.json` (only `github:exelight7/deadlock-fps-` is OFFICIAL); labels never come from an index; unreadable registry ⇒ everything UNVERIFIED.
* **Store/manager:** `<AppData>/repositories/{sources.json, state/<uid>.json, index/<uid>.json}`; `RepositoryManager.add/add_and_sync/import_config/export_config/remove/set_enabled/rename/refresh/refresh_all/list/get/index/search/categories/find_mod`. Failures become `SyncState(status='error')` and keep the last good catalogue.

## `installer/` (install engine, no Qt)
* Per game: `<game>/.deadlock-fps-studio/mods/` with `installed.json`, `journal.json`, `downloads/`, `staging/<tx>/`, `backups/<tx>/`, `trash/<tx>/`, `disabled/<uid12>/`.
* `Installer(root, transport, guard=None, studio=None, clock, free_space)`. `prepare(view, mod, version, progress, cancel)` → `InstallPlan` (download, SHA-256 check, inspect, stage as `pakNN_dir.vpk`, dependency/conflict blockers, overlap warnings, `requires_ack` for UNVERIFIED / derived / no hash). `commit(plan, acknowledged)` enforces the acknowledgement itself, checks the game is closed and staged hashes unchanged, calls `Studio.enable_addons()`, then runs the moves in one write-ahead-journaled transaction, verifies the installed files, writes `installed.json`, prunes backups (last 3 previous versions, last 5 removals). `_run_moves` never overwrites and undoes by replaying the journal backwards; `recover()` does the same at start.
* Also `uninstall(repo, mod, force)`, `set_enabled`, `restore_previous`, `analyze()` (inactive/missing/modified/damaged/overlap/dependency/unmanaged/unreadable), `repair()`, `unmanaged()`, `dependents()`, `history()`.
* Slots: lowest free `pakNN` skipping every existing `pakNN_dir.vpk` regardless of owner; reused on update; reserved while disabled; **lower number wins** in game. Error codes are stable strings in `installer/errors.py`; `hub_ui.failure_text` maps them to sentences.
* `installer/updates.py` `update_status(installed, manager, build)`; an update is taken only from the repository the mod came from; `GameFit.INCOMPATIBLE` blocks offering it.
* `records.py`: `InstalledMod(repository_id, mod_id, name, version, files, enabled, author, repository_name, trust, source_url, package_url, package_sha256, package_verified, installed_at, updated_at, dependencies, conflicts, previous, history)`; a damaged `installed.json` is renamed `installed.damaged-<ts>.json` before the first save.

## `store/` (mod store engine, no Qt)
* `gamebanana.py`: `GameBananaClient(transport)` over the existing pinned transport. `index_page(page, newest=False)` (50 per page, `Generic_Oldest` for crawls, `Generic_LatestModified` for refreshes), `categories(parent=None)`, `profile(id)`. Every response is untrusted: `parse_submission/parse_profile/parse_file` bound and clean every field; URLs are built from numeric ids; image URLs pass `safe_url` (https, GameBanana host, plain file name). Errors reuse `RepoError` codes plus `bad-response`.
* `catalog.py`: `Catalog(path)` SQLite (`user_version` 1) with FTS5 (falls back to LIKE). `save_page(items, snapshot, **meta)` writes rows and the cursor in one transaction; `query(text, category, subcategory, include_nsfw, include_obsolete, downloadable_only, sort, limit, offset)`; sorts are a whitelist (`updated`, `newest`, `name`, `popular`); `categories()`, `subcategories()`, `apply_profile()` (the only writer of likes/views/downloads), `meta`/`set_meta`. A damaged file is renamed `*.damaged-<ts>` and rebuilt.
* `sync.py`: `StoreSync(client, catalog, clock, sleep, pause=0.6, refresh_page_limit=20)`. `crawl()` resumes from `crawl_next`; `refresh()` stops at the first ordered page that reaches `high_water`; `sync()` crawls until a crawl has completed, then refreshes, falling back to a new crawl on `page-limit`. A 429 is a clean stop (`stopped='rate-limited'`), not an exception.
* Storage: `<AppData>/store/catalog.sqlite`. Meta keys: `crawl_snapshot`, `crawl_next`, `crawl_total`, `crawl_done`, `high_water`, `refreshed_at`.
* `install.py`: `build(profile, file)` → `(RepositoryView, Mod, ModVersion)` for the installer. Repository id `store:gamebanana` (`installer.updates.STORE_PREFIX = 'store:'` marks store installs), always UNVERIFIED; mod id `gb-<id>`; one version = the chosen file; `Package(format, url, size, None, (), md5, hosts=('gamebanana.com',))`; zip packages get `InstallSpec(discover=True)`; `file_format(file)` returns `('zip'|'vpk', '')` or `('', 'rar'|'7z'|'other')`.
* Engine additions for it (`installer/`): `archive.inspect_zip(..., discover=True)` (max 8 `.vpk`, none is an error), `Installer.prepare` checks `Package.md5` when there is no SHA-256 (`InstallPlan.md5_verified`) and discards a download whose final host is not in `Package.hosts` (then tries the next mirror). `ModService.prepare_store(profile, file_id, done, failed)` is the entry point; `commit`/`discard` are the Hub's.

## `perf/` (performance knowledge, no Qt) and the skip setting
* `facts.py` is **generated** (`scripts/dev/perf_facts.py`): `FACTS[name] = (status, since_build, valve_default)` for every setting the recipe can write, `CONVAR_BUILD`, `STOCK_BUILD`, `CHECKED_ON`. Do not edit by hand. `knowledge.py`: `ENTRIES[name]` = `Entry(name, category, effect, status, since, default, sight)` (explanations written here, `tr()`-wrapped), `CATEGORIES`, `STATUS_LABELS`, `STATUS_TEXT`, `PROTECTED`, `IGNORED = (removed, blocked)`. `explain.py`: `explain(settings)` → `Report(items, written, ignored, uncertain, sight, left_out)`, `ignored_names(settings)`. A test requires `ENTRIES`, `FACTS` and what `values()` can write to be the same set.
* `Settings.skip` (tuple of names, default empty): `values()` drops those names from the `gameinfo.gi` convars, the `SceneSystem` keys and the `video.txt` twin (`setting.<name>`); `validate()` refuses the protected names (`fps_max`, `fps_max_ui`, `r_aspectratio`), non-alphanumeric names and more than 200; `from_dict` turns a JSON list back into a tuple. `Studio` is unchanged: `plan()` starts from the baseline, so a name left out returns to the file's value.
* `perf_ui.PerfDialog(settings, level_name, parent)`: the table, filters, `skip()`. `ui.Window` has class attribute `skip`, `show_perf_details()`, `refresh_perf_button()`; `settings()` passes `skip`, `load_settings()` restores it (so loading a preset clears it).

## `stats/` (statistics engine, no Qt)
* `clean.py`: `clean(text, limit)`, `to_int`, `to_float`: strict readers for anything from the server (booleans, negatives, fractions, non-ASCII digits and non-finite numbers give the default).
* `maths.py`: `rate`, `kda` (a match without deaths counts one), `wilson(wins, matches)` 95 % interval. `steam.py`: `account_id(text)` for a 32-bit number, a 64-bit ID, `[U:1:n]` or a `steamcommunity.com/profiles/…` link (vanity `/id/name` raises `SteamIdError('vanity')`); `from_userdata_path(path)`. `model.py`: frozen `HeroStat`, `Meta`, `RankShare`, `Distribution`, `PlayerRank`, `Player`.
* `api.py`: `DeadlockApi(transport, clock)` over the pinned transport; fixed host `https://api.deadlock-api.com`; `heroes()`, `ranks()`, `hero_stats(window, mode, tier, names)`, `game_summary(...)`, `rank_distribution(window, mode, tier_names)`, `player_rank(account)`, `player_heroes(account, window, mode, names)`. Windows are 7/14/30 days, modes `''` (parameter left out), `ranked`, `unranked`; the start time is rounded to the hour so the same question gives the same address. The `parse_*` functions drop rows that contradict themselves and cut lists at 400. Errors are `RepoError` (`rate-limited`, `not-found`, `network`, `bad-response`).
* `cache.py`: `Cache(folder, clock)` JSON files under `<AppData>/stats/`, atomic writes, `get(key, ttl)` returns `(data, saved_at)` or None (old, future, corrupt, oversized all count as missing). `source.py`: `StatsSource(api, cache)` with `meta`, `distribution`, `hero_names`, `rank_names` (cache first, then server, then an older copy marked stale: `Loaded(value, error, cached)`), `cached_*` (disk only) and `player(account, window, mode)` (never cached).
* `stats_service.StatsService(folder, transport, clock)` runs `load_overview(window, mode, tier, refresh, done, failed)` and `load_player(...)` on `QThreadPool`, one at a time (`busy`, `busyChanged`), and offers `cached_overview(...)` for disk-only reads. `stats_ui.StatsPage(window, service, account)` (`account` is a callable returning the Steam account number or None; the main window passes `Window.steam_account`): changing a choice shows the saved copy and never starts a request; a counter drops answers to an older choice; numeric sorting through `NumberItem`. Tests use `StatsService(folder, transport=FakeServer())` from `tests/stats_fixtures.py`.

## UI layer
* `ModService(QObject)`: owns the manager, one cached `Installer` per game folder (recovery runs when it is first created; failure is emitted via `notice`, the installer is still returned), runs work on `QThreadPool` through its own coded job class, signals `changed/busyChanged/progress/notice`, methods `prepare/commit/discard/operate/run/cancel/game_build/statuses`.
* Pages never call engines for slow work directly. They use `ui_common` (`make_table`, `make_button`, `select_row`, `selected_data`, `ltr`, `size_text`, `scroll_column`) and the design system (`Panel`, `UtilityHeader`, `empty_state`, `Combo`, `text()` from `update_ui` for plain-text labels). **All text from repositories is shown as plain text** (labels with `PlainText`, `QTableWidgetItem`).
* `InstallReview` (pages/browse.py) gates its Install button on blockers and the acknowledgement checkbox; `BatchReview` (pages/installed.py) does the same for update-all.
* `store_service.StoreService` (own `_Job`; `busy` means a sync is running, profile fetches are untracked; `summary()`, `start_sync(done, failed)`, `cancel()`, `fetch_profile(id, done, failed)`) and `pages.browse.BrowsePage(service, mods=None)` (plain-text labels, the mod page fetched when a card is pressed, session profile cache, 48 cards at a time up to 300; with a `ModService` it also installs from the sheet: file picker, Install, its own `InstallReview` dialog, the same commit path; without one it only browses; see [[Browse Page]]). Tests patch nothing global: `StoreService(folder, transport=fake, pause=0)`.
* `graph_ui.GraphCanvas`: world↔screen transform, QPainter drawing with level-of-detail labels, hit testing, `Layout` stepping on a 16 ms timer, collapsed groups via `Graph.view()`. `GraphPage` builds with `build_graph(vault_dir, ROOT, manager, installed)`; `ROOT` is the source tree or the packaged resources.

## Graph data (`graph/`)
Kinds: module, feature, task, decision, doc, repository, mod, version, author, game. Edge kinds: publishes, has version, depends on, conflicts with, supports, by, contains, implemented by, describes, affects, links to. Notes come from `vault.read_vault`: `type` feature/decision/task else doc; `code:` paths that exist become module nodes grouped by package; `affects:` and `implements:` frontmatter become typed edges; note links are `links to` (hidden by default) unless a typed relation already joins the pair. Notes of `type: raw` are skipped.
