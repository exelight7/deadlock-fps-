# Design system

> **This is the old system (3.5 to 4.0).** It stays true for the code until the redesign replaces it. The new design is in [[01 Principles]] · [[02 Information Architecture]] · [[03 Visual Language]] · [[04 Components]] · [[05 Screens]] · [[06 Handoff to Build]] ([[Redesign Plan]]).

Pre-existing and kept: ink-black / dark-teal / aged-brass palette (art-deco), tokens in `theme.py` (pure data), a Qt stylesheet and cut-corner `Panel`/`ActionBar`/`UtilityHeader`/`EmptyState` widgets in `design.py`, eased motion in `motion.py`, original icons and illustrations generated by `scripts/make_assets.py`, bundled OFL fonts (Reem Kufi, Noto Sans, Noto Sans Arabic). Rules are written in `docs/DESIGN.md`. Dark theme only; no light theme exists (the brief's "if supported by the existing architecture" — it is not, and adding one is Milestone 7 scope).

## How the Repositories page uses it
* Header strip, then four cut-corner panels: add, your repositories, details, search. One readable column, max 1180 px, centred.
* Semantics of colour (never the only signal; every state also has text): verdigris = good/official, amber = caution/unverified/translated, crimson = failure, muted = not yet synced, off-grey = disabled repository.
* Empty states reuse the shipped illustrations (`empty-library`, `empty-search`).
* Right-to-left: the whole window mirrors; data cells that must stay left-to-right (versions, sizes, dates, addresses) are wrapped in LRM marks.
* Remote text is rendered as plain text and never as rich text ([[Security Model]]).

## Added in 4.0
* **Mod Manager rail group** (Mod Hub, Repositories, Installed Mods, Compatibility, Downloads, Mods) with a denser rail (36 px entries). The page switcher at the top lists the five most used of them.
* Every list is a table with a plain-text status in words and colour (verdigris = fine, amber = needs attention or caution, crimson = problem, muted = inactive); colour is never the only signal.
* Two-step destructive or installing actions: a review dialog that says what will change, where it came from and what is kept for recovery; acknowledgements are checkboxes that really gate the button.
* The graph canvas uses the same tokens plus two soft hues (documentation, decisions) so ten node kinds stay distinguishable; relationships are always also available as text.
* Right-to-left: whole window mirrors; data cells that must read left to right are wrapped in LRM marks; programmatic table selection avoids `selectRow` (see [[Known Issues]]).

## Gaps (Milestone 7)
Named pages instead of indexes; keyboard navigation audit (Tab order and accessible names exist on the new page's inputs, nothing systematic elsewhere); responsive layout below 940 px width (the window minimum); a light theme.
