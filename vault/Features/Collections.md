# Collections

**Status: PROPOSED.** A named set of mods (possibly from several repositories) that can be installed and shared together. The shareable *repository list* document ([[Repository Manager]], `deadlock-mod-repository-list`) is a related, already-implemented concept, but it shares **sources**, not mods. A collection would reference `(repository, mod, version)` triples and needs [[Installed Mods]] first.
