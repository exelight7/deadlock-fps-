# Security model

External repositories are welcome, but their content is untrusted and security is never weakened to make compatibility easier.

**Threats considered:** a malicious or compromised index; a malicious package; a repository aimed at the user's own network; a look-alike repository borrowing a trusted name; a man in the middle; resource exhaustion; UI injection through text; a crash or failure half way through an install.

## Repository side

| Control | Status | Evidence |
|---|---|---|
| HTTPS only, default port, no credentials, for the user's URL, every redirect hop and every URL inside an index | VERIFIED | tests; live: `http://` and `127.0.0.1` refused |
| Public hosts only; resolved address checked and **connected to directly** (no rebinding window) | IMPLEMENTED | fake resolver tests; not tested against a live rebinding setup |
| Certificate verification not disableable; only the HTTPS handler is reachable | IMPLEMENTED | handler list test; live TLS to github.com and gitlab.com |
| Size limits by header **and** while streaming, no compression, 45 s deadline, ≤ 5 redirects | VERIFIED | tests; live size cap and 404 |
| Index validation: limits, schema major, plain-text fields, bad entries skipped with warnings | IMPLEMENTED | `test_repos_core.py` |
| Trust from the shipped registry only; self-declared trust ignored; fail-safe to UNVERIFIED | IMPLEMENTED | [[Trust System]] |
| No hidden activity: no timers, no background sync, no automatic install | IMPLEMENTED | by design |

## Package and installation side

| Control | Status | Evidence |
|---|---|---|
| SHA-256 and declared size verified; mismatch discards the file; missing hash needs acknowledgement | IMPLEMENTED | tampered, short and oversized download tests; mutation-checked |
| Streaming download, constant memory, partial files removed, never deletes a file it did not create | VERIFIED | tests; live download through GitHub's redirect to another host |
| Archive inspection: unsafe paths, symlinks, encryption, case collisions, entry count, declared size, compression ratio; whole archive refused on any unsafe entry | IMPLEMENTED | `test_installer_inspect.py`; mutation-checked |
| Only listed `.vpk` members are extracted, counting real bytes; **no other file type is ever installed or executed** | IMPLEMENTED | zip tests; the spec cannot express anything else |
| VPK structural validation, bounds, single-file only | IMPLEMENTED | tests; mutation-checked |
| Install paths restricted to `game/citadel/addons`, names generated by the engine (never taken from the package) | IMPLEMENTED | slot tests |
| Staging in a private folder; stale-plan detection (hash recheck at commit) | IMPLEMENTED | mutation-checked |
| Backup, journaled moves that never overwrite, rollback, crash recovery | IMPLEMENTED | fault-injection tests incl. failing rollback and simulated power cut |
| Post-install verification before success is reported | IMPLEMENTED | corruption-after-copy test; mutation-checked |
| Source and trust shown before install; UNVERIFIED, derived entries and missing hashes need an engine-enforced acknowledgement | IMPLEMENTED | `test_installer_engine.py`, `test_mod_pages.py` |
| The game must be closed; no installation without a user action | IMPLEMENTED | tests |
| A publisher's MD5 is checked when no SHA-256 exists (store files); the plan says this detects damage, not tampering, and the acknowledgement is still required | IMPLEMENTED | `test_store_install.py`; mutation-checked |
| A package may name its hosts; a download that ends elsewhere after redirects is discarded | IMPLEMENTED | `test_store_install.py`; mutation-checked |
| Zip packages without a manifest: every `.vpk` is discovered (at most 8, none is refused) while every entry is still inspected | IMPLEMENTED | `test_store_install.py`; mutation-checked |

## Known limits
* A malicious index can point at a harmful `.vpk` with a matching hash. Hashes defend against corruption and swapped downloads; **trust labels defend against malicious publishers**, and only the project's own repository is labelled ([[Trust System]]).
* No package signatures. No sandboxing of what a VPK contains; VPK content is game data, not code.
* System proxies unsupported ([[Known Issues]]).
* Store files are checked with MD5 only: that catches damage, not a deliberately altered file from whoever controls the download. GameBanana's own antivirus verdict is shown but is not our check.
* Not exercised against a real game folder with real community mods. A store download was tried once, in a throwaway game folder.
* **Stats:** the statistics host is a constant and its answers are untrusted data (types and sizes checked, text cleaned, contradicting rows dropped, lists cut, JSON nesting bombs refused, hero names shown as plain text). Nothing is requested until a button is pressed. The Steam account number leaves the computer only through the **Look up** button, goes only to the player addresses, and is never written to disk (`test_stats_source.py`, `test_stats_ui.py`) ([[ADR-014 Statistics are fetched on request and nothing personal is kept]]). The service is community-run and its terms were not read ([[Known Issues]] #22).
